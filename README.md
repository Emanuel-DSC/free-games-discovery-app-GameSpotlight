# 🎮 GameSpotlight

A Flutter mobile application that helps users discover free games, explore details, and manage favorites with authentication and real-time data.

## ✨ Technologies & Architecture

### Tech Stack
- `Flutter`
- `Dart`
- `Firebase`
- `REST API (FreeToGame)`

### Architecture
- `MVC (Model-View-Controller)` Structure
- Firebase Authentication
- Modular and scalable design

## 🚀 Features

- **User Authentication:** Secure login and signup powered by Firebase.
- **Smart Discovery:** Browse and explore a vast catalog of free-to-play games.
- **Advanced Filtering:** Search and filter games dynamically by categories.
- **Detailed Insights:** View comprehensive game descriptions, requirements, and information.
- **Personalized Library:** Add, track, and manage your favorite titles in real-time.

## 📍 The Process

This project started from a very genuine, real-world need: my friends and I were always scouring the internet trying to find a cool, free game we could all play together. Instead of just continuing the endless search through messy websites, I decided to build a centralized solution. 

Developing **GameSpotlight** was an amazing journey in mastering mobile architecture. Integrating the FreeToGame REST API while managing asynchronous states in Flutter taught me a lot about smooth data parsing. I also wanted to ensure user data was secure and persistent, which led me to implement Firebase for robust authentication and real-time favorites tracking. Turning a daily problem with my friends into a polished, scalable application was incredibly rewarding!

## 🚦 Running the Project

1. Clone the repository: `git clone https://github.com/Emanuel-DSC/GameSpotlight.git`
2. Install dependencies: `flutter pub get`
3. Ensure you have a connected device or emulator running
4. Run the application: `flutter run`
