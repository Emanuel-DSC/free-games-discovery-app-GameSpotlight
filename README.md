

# 🎮 GameSpotlight

A Flutter mobile application that helps users discover free games, explore details, and manage favorites with authentication and real-time data.

<br>


## 🚀 Features

* User authentication (login & signup)
* Browse and discover free games
* Search and filter by categories
* View detailed game information
* Add and manage favorites

<br>


## 🛠 Tech Stack

Flutter • Dart • Firebase • REST API

<br>


## 🧠 Architecture

* MVC structure
* API integration (FreeToGame)
* Firebase authentication
* Modular and scalable design

<br>
